# Photon Reimagined - Legacy

**Minecraft 1.16+ - Iris 1.5+ / Oculus (Forge)**

> **This is the legacy branch.** For the current version with Visual Style profiles (Reimagined / Apocalyptic / Original), expanded quality presets, and all latest features, see [Photon Reimagined](https://github.com/realBritakee/photon-reimagined/tree/reimagined).

---

Photon Reimagined Legacy is an earlier fork of [Photon Shaders](https://github.com/sixthsurge/photon) by sixthsurge, featuring Physics Mod ocean support and Colorwheel integration with a custom visual style - without the newer profile system.

## What it includes

- Custom visual style - warmer colours, enhanced contrast, deeper shadows
- Physics Mod ocean wave support
- Colorwheel / Flywheel compatibility for Create mod contraptions
- Based on Photon's upstream codebase

## Mod Compatibility

- **[Physics Mod](https://minecraftphysicsmod.com/)** - ocean wave physics in the deferred pipeline
- **[Colorwheel / Flywheel](https://github.com/djefrey/Colorwheel)** - Create contraptions render correctly with full shading
