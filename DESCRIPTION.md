# Photon Reimagined

**Minecraft 1.16+ - Iris 1.5+ / Oculus (Forge)**

Photon Reimagined is a custom fork of [Photon Shaders](https://github.com/sixthsurge/photon) by sixthsurge, rebuilt with expanded visual styles, richer quality presets, and improved mod compatibility - while staying true to Photon's original gameplay-focused philosophy.

---

## Visual Style Profiles

Three distinct visual identities built into one shader pack. Switch between them in the Iris shader settings:

### Reimagined (Default)
The signature look. Warmer colours, enhanced contrast, deeper shadows, and richer sky atmosphere. Built for cinematic screenshots and immersive survival gameplay.

### Apocalyptic
Desaturated and heavy. Reduced brightness, muted colours, thick fog, and a harsh sun create a post-apocalyptic visual tone perfect for zombie survival modpacks.

### Original
Faithful to the upstream Photon Shaders look. Clean, neutral, and performance-focused - the classic Photon experience without any Reimagined modifications.

---

## Quality Presets

Seven tiers of quality - from toasters to high-end GPUs:

| Preset | Target Hardware |
|--------|----------------|
| Potato | Integrated graphics, very old GPUs |
| Very Low | Entry-level dedicated GPUs |
| Low | Budget GPUs (GTX 1050 / RX 570) |
| Medium | Mid-range GPUs (GTX 1660 / RX 5600) |
| High | Modern mid-range (RTX 3060 / RX 6700) |
| Very High | High-end GPUs (RTX 3080 / RX 6900) |
| Ultra | Enthusiast hardware only |

## Mod Compatibility

- **[Physics Mod](https://minecraftphysicsmod.com/)** - realistic ocean wave physics rendered correctly in the deferred pipeline
- **[Colorwheel / Flywheel](https://github.com/djefrey/Colorwheel)** - Create mod contraptions and entities render with full Photon shading and shadows
